### На главной странице есть список задач и кнопка «Добавить задачу». На карточке задачи отображена информация по ней и есть кнопки редактирования и удаления.
В верстке сейчас отображается значения enum вместо нужного текста в полях «Статус» и «Приоритет».
Необходимо вместо этого вывести текст на русском «Высокий», «Низкий» и так далее для приоритета; «Сделано», «В прогрессе» и так далее — для статуса.

### При клике на кнопку «Добавить задачу» открывается модальное окно добавления задачи.

### При клике на кнопку «Добавить» модальное окно должно закрываться, а задача отображаться в списке на первом месте.
При клике на иконку редактирования на карточке задачи должно открываться окно добавления задачи с информацией о ней (title и priority) со следующими изменениями:

Вместо заголовка «Добавить задачу» заголовок «Редактировать задачу»

Вместо текста на кнопке «Добавить» — «Редактировать»

### При клике на кнопку «Редактировать» задача должна сохраняться.
При клике на иконку удаления должно открываться модальное окно с подтверждением удаления.
При клике по кнопке «Удалить» модальное окно должно закрыться, а задача удалиться из списка.

## Требования:
- Сформировать файловую структура проекта, опираясь на модульную структуру
- Добавить state к компонентам, чтобы проект стал рабочим
- Типизировать все необходимые переменные и константы, в том числе Props
- Выводить вместо enum в Priority и Status текст на русском языке на карточке товара и в окне создания/редактирования задачи

#### Примечания:
- В проекте уже добавлен список задач в файле serverData/taskList.ts (по желанию можно использовать, например, https://jsonplaceholder.typicode.com/ для полноценной имитации работы с API, эндпоинты могут не работать без VPN)
- Все модальные окна должны закрываться при нажатии на иконку крестика
